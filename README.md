# LEKKO APP — Структура базы данных

## Общая информация

**СУБД:** PostgreSQL
**Хостинг:** Railway (проект zealous-vibrancy)
**Подключение:** через переменную окружения `DATABASE_URL`
**ORM:** asyncpg (прямые SQL запросы, без ORM)
**Бэкенд:** Python (`lekko.py`), aiohttp HTTP сервер + aiogram Telegram бот
**Фронтенд:** Vanilla JS (`app.js`), данные частично дублируются в localStorage браузера

---

# Таблицы PostgreSQL

## 1. users — Пользователи

Хранит всех сотрудников, которые хотя бы раз запустили бота командой `/start`.

| Колонка    | Тип                | Описание                             |
| ---------- | ------------------ | ------------------------------------ |
| id         | BIGINT PRIMARY KEY | Telegram user ID                     |
| username   | TEXT               | Telegram @username (может быть NULL) |
| first_name | TEXT               | Имя пользователя в Telegram          |
| created_at | TIMESTAMP          | Дата первой регистрации              |

### Когда записывается

При каждом вызове `/start` запись создаётся или обновляется:

```sql
INSERT ... ON CONFLICT DO UPDATE
```

## 2. shifts — Смены

Хранит все рабочие смены сотрудников — начало, конец, геолокацию, продолжительность и расстояние.

| Колонка     | Тип                | Описание                                                                    |
| ----------- | ------------------ | --------------------------------------------------------------------------- |
| id          | SERIAL PRIMARY KEY | Автоинкрементный ID                                                         |
| user_id     | BIGINT             | Telegram ID сотрудника                                                      |
| first_name  | TEXT               | Имя сотрудника                                                              |
| start_time  | TEXT               | Время начала смены (HH:MM)                                                  |
| end_time    | TEXT               | Время завершения смены (HH:MM), NULL если смена ещё идёт                    |
| worked      | TEXT               | Продолжительность смены (например "4ч 32м")                                 |
| latitude    | FLOAT              | Широта точки завершения смены                                               |
| longitude   | FLOAT              | Долгота точки завершения смены                                              |
| map_link    | TEXT               | Ссылка Google Maps на точку завершения смены                                |
| date        | TEXT               | Дата смены в формате YYYY-MM-DD                                             |
| distance_km | FLOAT              | Расстояние по прямой от старта до финиша (км), считается формулой Haversine |
| created_at  | TIMESTAMP          | Время создания записи в БД                                                  |

### Когда записывается

#### Начало смены

Сотрудник нажимает **«Начать смену»** в WebApp:

```text
app.js
   ↓
event: shift_start
   ↓
сервер
   ↓
создаётся новая запись
```

Создаются:

* start_time
* координаты старта
* end_time = NULL

#### Завершение смены

Сотрудник нажимает **«Завершить смену»**:

```text
app.js
   ↓
event: shift_end
   ↓
находится последняя незакрытая смена
   ↓
обновляются поля
```

Обновляются:

* end_time
* worked
* координаты финиша
* distance_km

> Примечание: `latitude` и `longitude` в таблице содержат координаты завершения смены. Координаты начала смены хранятся только в localStorage браузера (`shift_start`) и в `map_link`.

## 3. pharmacies — Аптеки

Хранит все добавленные сотрудниками аптеки с полными данными о контакте, геолокацией и статусом.

| Колонка      | Тип                | Описание                      |
| ------------ | ------------------ | ----------------------------- |
| id           | SERIAL PRIMARY KEY | Автоинкрементный ID           |
| user_id      | BIGINT             | Telegram ID сотрудника        |
| first_name   | TEXT               | Имя сотрудника                |
| name         | TEXT               | Название аптеки               |
| lpr_name     | TEXT               | ФИО ЛПР                       |
| lpr_phone    | TEXT               | Телефон ЛПР                   |
| software     | TEXT               | Используемая программа        |
| software_id  | TEXT               | ID программы                  |
| status       | TEXT               | Статус контакта               |
| comment      | TEXT               | Комментарий                   |
| photos_count | INT                | Количество прикреплённых фото |
| latitude     | FLOAT              | Широта аптеки                 |
| longitude    | FLOAT              | Долгота аптеки                |
| map_link     | TEXT               | Ссылка Google Maps            |
| created_at   | TIMESTAMP          | Дата и время добавления       |

### Когда записывается

```text
Заполнение формы
      ↓
Получение геолокации
      ↓
event: pharmacy_add
      ↓
Создание записи в PostgreSQL
```

### Значения поля status

| Значение | Описание            |
| -------- | ------------------- |
| cold     | ❄️ Холодный контакт |
| inwork   | 🔄 В работе         |
| deal     | ✅ Договорились      |
| decline  | ❌ Отказ             |

# Поток данных

```text
Сотрудник (WebApp)
        │
        │  fetch POST /event
        ▼
lekko.py (Railway HTTP сервер)
        │
        ├──► PostgreSQL (сохраняет данные)
        │
        └──► Telegram Bot API
                  │
                  ├──► Сотруднику (подтверждение)
                  └──► Админу (уведомление)
```
